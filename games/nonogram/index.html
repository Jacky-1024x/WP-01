玩法说明

  • 行左侧、列上方的数字表示这一行（列）里连续涂黑的格子分成几段、每段多长，段与段之间至少隔一格。
  • 根据数字推理，把该涂的格子全部涂黑，就会拼出一幅图。
  • 底部切换「涂黑 / 打叉」。打叉表示“这里一定是空白”，只是记号，不打也能完成。
  • 按住格子拖动可沿一行或一列连续操作；用同一种笔点已标记的格子可以擦除。
  • 某行（列）的标记与数字对上后，数字会变灰。
  • 每道题都只有唯一解，而且不需要猜。
  • 10×10、15×15 可用棋盘右下角按钮或双指捏合放大，放大后在棋盘区域拖动查看；格子上仍可拖动连涂。
  • 电脑上：左键用当前笔，右键用另一种笔；方向键 + 空格 / F / X 也可以操作，Tab 切换笔，Ctrl/⌘ + Z 撤销。
