玩法说明

  • 棋盘被分成 N 块彩色区域。放下 N 个皇后，使每行、每列、每块颜色都恰好有一个皇后。
  • 任意两个皇后不能相邻，斜对角挨着也不行。
  • 轻点格子：空 → ✕ → 皇后 → 空。双击直接放皇后，按住拖动连续打叉（从 ✕ 开始拖则连续擦除）。
  • 「自动打叉」开启时，皇后攻击范围内的格子显示小圆点。冲突的皇后会标红。
  • 每道题只有唯一解，而且不用猜。卡住了可以点「提示」看下一步怎么想。
  • 键盘：方向键移动，空格轻点，Q 皇后，X 打叉，H 提示，P 暂停，Ctrl/⌘ + Z 撤销。
